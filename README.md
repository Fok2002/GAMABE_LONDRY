# GAMABE Laundry

A polished, responsive one-page website for GAMABE Laundry in Busanza, Kigali. It presents the laundry's clothes, shoe, and home-essential cleaning services, explains the process, and includes a lightweight booking request form.

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

The site uses Google Fonts and Unsplash image URLs, so an internet connection is needed for the intended visual experience.

## Project files

- `index.html` - page structure, content, and accessible form markup
- `styles.css` - responsive layout and visual system
- `script.js` - mobile navigation and booking form feedback

## Deploy to GitHub Pages

1. Create or connect the repository `git@github.com:Fok2002/GAMABE_LONDRY.git`.
2. Push the project to the `main` branch.
3. In GitHub, open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The static site will then be available at the repository's GitHub Pages URL.

## Business details to confirm

The phone number, email address, and street address shown in the page are starter contact details for the design. Replace them in `index.html` with GAMABE Laundry's confirmed information before launch.
